# Social media (Instagram, TikTok, Facebook)

| Rule | Detail |
|---|---|
| Chat scope | The social chat is for organic posts only; never touch paid ads there |
| Priorities | Reels first, daily posts, keywords, expat buyers; no carousel if a reel exists |
| Designs | Use the approved scripts: carousels `carousel_project_v2_light.py` / `carousel_land_v2_light.py`, covers `reel_cover_light.py`, reels via the Remotion template; change only the data |
| Look | Brand orange `#f99958` accent on social, logo top-left in the safe area, grid lines at the top AND bottom, same on covers, reels and carousels; land = light sage + green, projects = orange bar |
| Carousel | Bold 50px headline, 18px light bar label on a 34px bar, white link strip with `www.` link, long black arrow on swipe slides, last slide black LINK IN BIO box |
| Reel text | Bomb drop on 1-2 scenes, tiny LINK IN BIO, no repeated place names, sharp photo window, regular weight uppercase, "2 AND 3 BEDROOMS" |
| Developers | Never tag or name developers |
| Every post | Set the location, Crop Original, caption, hashtags; log it in `social-posts` so /links updates |
| Links | Facebook captions: plain URL without UTM or no URL when the link allowance is used; TikTok/Instagram use `/go/ig|tt/<slug>` short links |
| Skip | Sold-out listings; listings already posted |
| Files | Copy finished files to a Desktop folder for the owner |
| Posting | Owner posts manually unless told otherwise; confirm before publishing |
