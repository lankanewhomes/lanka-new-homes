# How to reply to the owner

| Rule | Detail |
|---|---|
| Tables only | Every reply is a table. No prose paragraphs, no bullet or numbered lists. ("Only table, please. From any session, only give me table." 2026-11-15; "all table please i hate bulleted points" 2026-11-02) |
| Status dots | Start each row, or use a Status column, with a dot: 🟢 done / working / good, 🟡 waiting / partly done / needs attention, 🔴 failed / blocked / not done, ⚪ not applicable / left alone on purpose (2026-11-15) |
| Say what was NOT done | Name anything skipped, unchecked or unverified in its own row. Do not claim a green build when CI does not run |
| Plain words | Short cells, no jargon, no long explanations. Ask nothing the code or the docs already answer |
| Counts and costs | When asked "how many / what does it have", give counts per group and the reason for every gap |
| Links | Give the live link and, for backend work, the `/dashboard/...` link |
| Progress | After a push, say whether it is live (check the live page), not just pushed |
| Files for the owner | Copy them into a Desktop folder (see `owner-preferences.md`) |
