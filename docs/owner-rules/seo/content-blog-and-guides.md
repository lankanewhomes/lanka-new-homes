# Content: blog, guides, neighbourhood text

| Type | Rule |
|---|---|
| Blog posts | Config in `src/lib/blog.ts` (add a record, add a route); answer-first intro; 10 internal links out, link in from related pages; BreadcrumbList and BlogPosting JSON-LD; descriptive alt text; images on R2 under `blog/<slug>/`; listed in `/llms.txt`; no FAQ block |
| Topics | Buyer questions from real sources (Reddit r/srilanka: deeds not given on time, build quality, show units, late handover, land vs apartment vs house) and developer-side topics |
| Guides | `src/lib/guides.ts`: foreigners buying property, investment property, golden visa; keep FAQs here |
| Neighbourhood pages | Facts from Wikipedia/official sources, one credited Commons photo, short factual text (80-165 words minimum), a real listing count in the title, a "Land for sale in {Name}" section; no promotional claims |
| Voice | Plain, factual, no invented claims, no developer names in promotional posts |
| Publishing | Draft first; publish only when the owner says; add to sitemap and `/llms.txt` |
| After | Add to `docs/seo-strategy.md`, request indexing (owner), check it with the SEO tools |
