# Brand colours

| Use | Value | Notes |
|---|---|---|
| Brand accent orange | `#f47b36` | Active tab underline, primary buttons (Sign up, Request info, search submit), project map pin. Never yellow `#ffc52d`/`#FFC85A` (owner, 2026-10-31, "remember branding") |
| Darker orange | `#c85f24` | Active map marker, Premium accent |

| Text on orange | dark ink, not white, on social graphics | White on orange has poor contrast |
| Ink | `#1f1f1f` | Headings and main text |
| Muted text | `#6b6355` (warm), stone-500 | Sub-headings, captions |
| Page | white | Neutral palette is Tailwind `stone-*` for borders and muted text |
| Warm hover / light row | `#f7f6f2` | Hover rows, soft fills |
| Hairline | `#e4e0d6` (warm) / `#ececec` (neutral) | Row and box borders |
| Key Features open row | background `#fdf3e0`, text `#92670c`, left bar `#f2d38a` | Do not change |
| Key Features room box | `#fafafa` very light grey (owner-approved 2026-11-15) | Never a warm tint, never darker |
| Soft section backgrounds | `#f1f0ec`, `#f7f1e6`, `#ecf1ea`, `#f1ecf3` | Flat, texture-free, no blue |
| Land | sage `#e8ede2` background, green `#3D5A35` bars | Lands use green, projects use orange |
| Sold Out | solid red `#c0392b`, white text | Same red on hero tag, cards, map popup, plan pill |
| Pill palette | green `#1a6b2f`/`#e8f4e8`, blue `#1a53a3`/`#e8f1fd`, red `#c0392b`/`#fdeaec`, purple `#4338ca`/`#eef2ff` | Status and badge pills |
